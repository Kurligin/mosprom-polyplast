# Путь сотрудника: оператор производства, площадка GTP

Маршрут сгенерирован сквозным тестом `tests/e2e/test_e2e_journey.py` по настоящему коду бота: сценарий из xlsx, опросы, база знаний, сигналы, обращения, задачи руководителя. API «МАКС» фейковый, база тестовая, время двигает машина времени. Фейковый API разрешает боту добавить новичка в чат команды; настоящий «МАКС» с 9 сентября ботам это не даёт, поэтому бот присылает ссылку. **Все люди и данные синтетические.**

Обновить: `docker compose exec -T app pytest -q tests/e2e`.
