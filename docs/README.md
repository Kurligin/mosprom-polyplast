# docs

Здесь в рабочей версии лежат материалы кейса в Markdown: правила внутреннего трудового распорядка,
политики компании, сценарий текущего бота. Это внутренние документы заказчика, в публичную версию
они не входят.

Чтобы бот отвечал по своим документам, положите их сюда в Markdown (или загрузите PDF / PPTX через
панель HR) и выполните `make kb`. Тесты, которым нужен текст документов, без них пропускаются.
