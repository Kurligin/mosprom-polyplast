## Важно: синтетические и авторские данные

**07-survey-answers-synth.jsonl — полностью синтетический набор.** Это не ответы реальных сотрудников
ПОЛИПЛАСТИК. Тексты написаны нами для демо и проверки sentiment/флагов: разговорный стиль, опечатки,
сарказм, скрытые сигналы. Имена в текстах («Анна», «Сергей Петрович», «Лена») вымышлены.
В презентации и README репозитория показывать с пометкой «синтетические данные».

- Поля: `id, question (ключ_вопроса: формулировка), text, label (positive|neutral|negative), flags, cluster_hint, site (GrPP|GTP|Luzhniki), role (office|production), day_of_adaptation`.
- Ключи вопросов привязаны к опросам из ТЗ: `d1_access` (день 1), `d3_*` (опрос дня 3), `w2_*` (чек 2 недель),
  `m1_plan` (1-й день 2-го месяца), `m2_*` (опрос 2 месяцев, день ≈52), `fin_*` (финальный опрос, день 90).
- Распределение: negative 54 / neutral 40 / positive 26; GTP 51, GrPP 38, Luzhniki 31; office 73, production 47.
- С флагами 43 из 120 (36 %): intent_to_leave 11, conflict_manager 10, unclear_tasks 8, safety_issue 7,
  toxicity 6, overload 5, burnout 5, no_access 4, conflict_mentor 3. Набор специально немного сдвинут в негатив,
  чтобы демо дайджеста было наглядным.
- Есть трудные случаи: сарказм с позитивной лексикой (`s047`, `s103`), скрытые сигналы при нейтральном тоне
  (`s030`, `s101`, `s108`), шум (`s029`, `s034`, `s087`), вопросы к БЗ вместо отзыва (`s033`, `s096`) —
  на них стоит смотреть отдельно при оценке.
- Разметка одним аннотатором, без согласования — это ориентир, а не ground truth.

**06-golden-set.jsonl — авторский эталон**, ответы сформулированы нами по `inbox/kb/*` и сценарию ТЗ.
- 50 `answerable`, 15 `escalate` (бот может процитировать общую норму, но решение — живой HR), 8 `out_of_kb`
  (бот честно говорит «не знаю» и передаёт HR).
- `source_ref` указывает пункт и страницу ПВТР или номер слайда; для ПВТР текст получен OCR — цифры сверены
  с распознанным текстом, но не с оригиналом построчно.
- Вопросы про транспорт, обед, Лужники (`g046`–`g048`) отвечаемы только «в рамке» сценария ТЗ: самих маршрутов,
  меню и карт в материалах нет, ответ отсылает к статье площадки, которую заполняет HR.
