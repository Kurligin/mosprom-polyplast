# Корневые сертификаты НУЦ Минцифры

Нужны для `platform-api2.max.ru` и GigaChat API. Источник: gu-st.ru (Госуслуги). Публичные, не секрет.

- `russian_trusted_root_ca.pem` — Russian Trusted Root CA (до 2032)
- `russian_trusted_sub_ca.pem` — Russian Trusted Sub CA (до 03.2027)
- `russian_trusted_ca_bundle.pem` — оба вместе, путь задаётся в `CA_BUNDLE_FILE`
