# Mini App «Корсик»: панель HR и руководителя

React + Vite. Открывается внутри мессенджера «МАКС» кнопкой бота, в разработке работает в обычном браузере.

## Запуск

```bash
docker compose up -d          # из корня репозитория
open http://localhost:5173    # панель HR с горячей перезагрузкой
```

Полезные параметры адреса:

| Адрес | Что будет |
|---|---|
| `/?role=manager` | экран руководителя; в разработке бэкенд отвечает как первый руководитель (заголовок `X-Dev-Role`) |
| `/?mocks=1` | только демо-данные, сервер не нужен |
| `/?start=ticket_12`, `/?start=employee_5` | сразу открыть обращение или карточку, как по кнопке из бота |

Проверка сборки: `docker compose exec miniapp npm run build` (сначала `tsc`, потом `vite build`).

## Откуда данные

- Все экраны ходят в настоящий API (`/api/...`, контракт в [API.md](API.md)).
- Демо-данные включаются, только если сервер недоступен (сеть, 5xx), эндпоинт ещё не готов (`501`) или задан `?mocks=1` / `VITE_USE_MOCKS=1`. На таком экране в заголовке плашка «демо-данные».
- Ошибки 4xx показываются текстом из `detail` с кнопкой «Повторить». Действия на живых данных в демо не подменяются: если сервер не ответил, вы увидите ошибку.
- Каждый запрос несёт заголовок `X-Max-Init-Data` со строкой `initData` из моста «МАКС». «МАКС» передаёт её в адресе (`#WebAppData=…`), мост кладёт её в `sessionStorage`. Вне «МАКС» заголовок пустой, и бэкенд пускает такой запрос как HR, только если `DEV_ALLOW_NO_INIT_DATA=true`.

## Как открыть внутри «МАКС»

«МАКС» открывает Mini App только по HTTPS. Нужны три шага: адрес, регистрация адреса у бота и `.env`.

### 1. HTTPS-адрес на своём домене

1. Поддомен с A-записью на IP сервера с Docker, например `korsik.example.ru`. Порты 80 и 443 открыты.
2. Собрать фронт: `docker compose exec miniapp npm run build`, папку `miniapp/dist` положить на сервер.
3. Добавить в compose сервис `caddy` (образ `caddy:2`, порты 80 и 443) с таким `Caddyfile`:

   ```
   korsik.example.ru {
     encode zstd gzip
     handle /api/* {
       reverse_proxy app:8000
     }
     handle {
       root * /srv/miniapp
       try_files {path} /index.html
       file_server
     }
   }
   ```

   и смонтировать `./miniapp/dist:/srv/miniapp:ro`. HTTPS-сертификат Caddy получит сам.

Адрес не меняется, регистрировать его у бота нужно один раз.

### 2. Зарегистрировать адрес у бота (нужен вход владельца бота)

1. Откройте [business.max.ru/self](https://business.max.ru/self) (или мини-приложение «MAX для бизнеса»).
2. Раздел **«Чат-боты»** → **«Перейти»**.
3. У тестового бота нажмите **«⋮»** → **«Настройки»**.
4. В поле ссылки на мини-приложение вставьте HTTPS-адрес из шага 1, без пути и параметров, например `https://korsik.example.ru`.
5. Выберите вид кнопки (например, **«Открыть»**) и нажмите **«Сохранить»**.

Требования «МАКС» к адресу: только HTTPS, латиница, цифры, точки и дефисы, не длиннее 1024 знаков.

### 3. `.env` в корне репозитория

```
MAX_BOT_NAME=<имя бота без @, как в ссылке max.ru/<имя>>
MINIAPP_URL=https://korsik.example.ru
DEV_ALLOW_NO_INIT_DATA=false
```

- `MINIAPP_URL` включает в сообщениях бота кнопки «Открыть панель» и «Открыть в Mini App». Сама кнопка открывает тот адрес, что записан в настройках бота на business.max.ru, поэтому при смене адреса обновите оба места.
- `DEV_ALLOW_NO_INIT_DATA=false` на показе: внутри «МАКС» `initData` есть всегда, а без неё панель открываться не должна.
- После правки пересоздайте сервис: `docker compose up -d app`. Простой `restart` новые переменные не подхватит.

### 4. Проверить

1. Привяжите аккаунт HR кодом из `make links`. Бот пришлёт кнопку «Открыть панель».
2. Внутри «МАКС» не должно быть плашки «демо-данные», кнопка «назад» системная (своя в шапке скрыта).
3. Если видите «Не получилось подтвердить вход», бэкенд не принял подпись `initData`: проверьте токен бота в `.env` или откройте панель заново (подпись живёт 24 часа).
4. Кнопка «Открыть в Mini App» из уведомления об обращении открывает сразу это обращение (`start_param = ticket_<id>`).

Выбор файлов (документ, сценарий, план) внутри «МАКС» стоит проверить на реальном iOS и Android: окно выбора файла показывает сам мессенджер.
