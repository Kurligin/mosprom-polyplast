# Корсик 2.0

[![Корсик 2.0: ИИ-ассистент адаптации новых сотрудников в «МАКС». Открыть презентацию](media/hero.webp)](https://mosprom-polyplast.rapira-cloud.ru)

ИИ-ассистент адаптации новых сотрудников в мессенджере «МАКС» и панель для HR и руководителей прямо внутри «МАКС». Решение кейса ООО «Группа ПОЛИПЛАСТИК», хакатон «Открой Моспром», 2026.

Сейчас у компании Telegram-бот «Корсик» на жёстком кнопочном сценарии из 68 шагов. Корсик 2.0 переносит этот сценарий в «МАКС» целиком и добавляет то, чего не хватало: ответы на свободные вопросы по документам компании, разбор обратной связи, передачу проблем HR и аналитику для руководителей.

> [!IMPORTANT]
> **ИИ не пишет норму.** На вопрос новичка бот отвечает дословным пунктом документа с источником («ПВТР, п. 6.5.2, стр. 15»). Модель только выбирает подходящий пункт из пяти найденных. Если ответа в документах нет, бот честно говорит «не знаю» и передаёт вопрос HR. Ответ HR можно одной кнопкой добавить в базу, и в следующий раз бот ответит сам.

<details>
<summary><strong>Все возможности по ролям</strong></summary>

**Новый сотрудник (бот в «МАКС»)**
- Подключается по ссылке или QR из оффера. Знакомство одним сообщением, которое меняется на месте: «ты» или «вы», согласие на сопровождение, отдельное согласие на ИИ-разбор ответов.
- Получает все 68 шагов сценария по расписанию. Подряд идущие шаги склеиваются.
- Задаёт вопрос своими словами и получает дословный пункт документа с источником. Личные вопросы сразу уходят HR.
- Проходит опросы из ТЗ: 1-й и 3-й день, 2 недели, адаптационный план, 2 месяца, конец испытательного. При оценке ниже 8 или ответе «нет» бот спрашивает «что мешает?». Если опрос не пройден, напоминает на следующий рабочий день и через день.
- В первый рабочий день бот сам добавляет новичка в чаты команды. Если не пустили настройки приватности, присылает ссылки. С согласия новичка публикует его рассказ о себе в чате команды.

**HR-менеджер (панель в «МАКС» и HR-группа)**
- Список новичков по площадкам: день, этап, непройденные опросы, обращения, подключился ли.
- Заводит новичка за минуту и получает ссылку и QR для оффера.
- Отвечает на обращения из панели. Хороший ответ после подтверждения попадает в базу знаний, и бот дальше отвечает сам.
- Обновляет базу без программиста: загружает PDF, PPTX и новый xlsx сценария, в том числе с новой площадкой.

**Руководитель подразделения**
- Напоминание «проведи встречу» с кнопкой «Провёл».
- Экран «Мои новички» без опросов и обращений.

**Руководитель HR**
- Экран «Аналитика»: зоны риска с причинами, темы трудностей с динамикой и обезличенными цитатами, воронка этапов.
- Еженедельная сводка картинкой.

**Анализ обратной связи**
- Красные флаги ловятся словарём в любом сообщении и в любом состоянии диалога. Новичок получает ответ «увидит только HR» и, если нужно, номер 112.
- С согласия новичка ИИ определяет у свободного ответа тему, настроение и цитату-доказательство. Тексты о здоровье в модель не отправляются.

</details>

## Эффект для компании

Расчёт на консервативных допущениях, их стоит заменить цифрами компании. В презентации это калькулятор, параметры можно двигать.

| Допущение | Значение |
| --- | --- |
| Новичков в год | 500 |
| Уходят на испытательном сроке | 15% |
| Удержим дополнительно | 3 п. п., то есть 15 человек в год |
| Зарплата | 105 000 ₽ в месяц |
| Стоимость замены сотрудника | 21% годового дохода (оценка АНКОР) |
| Вопросов к HR на новичка | 10, по 5 минут на ответ |
| Бот отвечает сам | 64%, как на эталоне |

**Итого: около 4 млн ₽ в год на замене людей** (15 × 105 000 × 12 × 0,21 = 3 969 000 ₽) и **267 часов HR в год**: бот сам ответит на 3 200 вопросов.

## Кому и зачем

- **Рабочий на производстве.** Нет рабочей почты и компьютера, есть телефон с «МАКС». Первые дни ему нужно понять, где пропуск, откуда автобус, когда зарплата и кто наставник. Поэтому всё происходит в мессенджере, а не в портале.
- **HR-менеджер.** Тратит до 40% времени на разбор ответов в опросах и типовые вопросы (по данным кейса). Ему нужны только случаи, где нужен человек.
- **Руководитель подразделения.** При активном участии руководителя шанс на хорошую адаптацию в 3,4 раза выше ([Gallup](https://www.gallup.com/workplace/247172/problems-onboarding-program.aspx)). Поэтому бот не заменяет его, а напоминает о встречах.
- **Руководитель HR.** Нужно видеть проблему до заявления на увольнение: 40% сотрудников задумывались об уходе в первые месяцы, у 58% из них ожидания не совпали с реальностью ([hh.ru и Edstein, 2024](https://new-retail.ru/novosti/retail/issledovanie_40_sotrudnikov_zadumyvalis_ob_uvolnenii_v_pervye_mesyatsy_raboty/)).

## ИИ работает в закрытом контуре

Все модели решения можно поставить на сервер компании. ИИ делает две небольшие задачи: выбирает подходящий пункт из пяти найденных и разбирает свободные ответы в опросах. Всё остальное работает без модели.

| Задача | Чем делаем | Где работает |
| --- | --- | --- |
| Поиск по документам | bge-m3 (открытые веса) и полнотекстовый поиск Postgres | всегда на сервере компании |
| Выбрать пункт, разобрать ответ опроса | открытая модель на сервере компании через OpenAI-совместимый API, например GigaChat 3 Lightning (веса открыты под MIT) | на сервере компании |
| Личные вопросы, красные флаги, маскирование ФИО и телефонов | правила и словари | всегда локально |

Режим выбирается в `.env`:

| Режим | Настройки |
| --- | --- |
| Закрытый контур, своя модель | `LLM_PROVIDER=openai`, `LLM_BASE_URL=http://<сервер модели>/v1`, `LLM_MODEL=<имя модели>`, при необходимости `LLM_API_KEY` |
| Демо-стенд, GigaChat API | `LLM_PROVIDER=gigachat`, `GIGACHAT_CREDENTIALS`, `GIGACHAT_SCOPE`, `GIGACHAT_MODEL` |

- Если модель недоступна, бот всё равно работает: при уверенном поиске отвечает пунктом сам, иначе передаёт вопрос HR.
- Персональные данные маскируются перед любым вызовом модели, фрагменты с грифом коммерческой тайны в модель не отправляются.

<details>
<summary><strong>Сервер без интернета</strong></summary>

- Модель эмбеддингов кладётся в том `models` заранее (один раз запустить `make kb` там, где есть интернет, и перенести том) или указывается локальный путь: `EMBEDDING_MODEL=/models/bge-m3`.
- В `.env` добавить `HF_HUB_OFFLINE=1`, чтобы приложение не обращалось к HuggingFace.
- Наружу остаётся только Bot API «МАКС»: без него мессенджер не работает.

</details>

## Данные и безопасность

- **Ответы только из документов.** Бот цитирует пункт дословно и показывает источник. Вопрос вне базы уходит HR.
- **Маскирование.** Перед вызовом модели ФИО всех сотрудников, телефоны, e-mail и номера документов заменяются метками. В журнал вызовов пишутся только время, тип вызова и классы данных, без текстов.
- **Согласия.** ИИ-разбор ответов идёт только с отдельного согласия новичка. Без него всё остальное работает так же.
- **Доступ к панели.** Вход только через «МАКС»: подпись `initData` проверяется по токену бота. Руководитель видит только своих новичков, без опросов и обращений.
- **Срезы от 5 человек.** Аналитика по площадке показывается, только если ответили 5 и больше новичков.
- **Демо-данные** синтетические и помечены. Демо-функции (машина времени) в проде выключены и не работают для живых новичков.
- **Документы заказчика** (`docs/`) это внутренние материалы, в открытый доступ не выкладываются.

## Запуск: env и одна команда

Нужен Docker (Docker Desktop на Mac, образы собираются и под arm64). Python и Node ставятся в образах.

```bash
cp .env.example .env        # токен бота «МАКС» и ключ GigaChat или адрес своей модели
docker compose up -d --build
make seed                   # демо-данные, все синтетические
make import                 # сценарий из xlsx (data/raw/, в git не хранится)
make kb                     # база знаний: документы и статьи сценария
make links                  # ссылки привязки для тестовых новичков и персонала
```

- API: http://localhost:8000/health, Mini App: http://localhost:5173, Postgres: `localhost:5433`.
- Миграции применяются при старте `app`, вручную: `make migrate`.
- Прочее: `make logs`, `make test`, `make cov`, `make eval`, `make eval-flags`, `make psql`, `make shell`, `make down`.
- Чтобы не запускать опрос бота (если его уже опрашивает другой экземпляр с тем же токеном), добавьте в `.env` строку `BOT_ENABLED=false`.

<details>
<summary><strong>Запуск на сервере: свой домен и HTTPS</strong></summary>

Нужны сервер с Docker, поддомен с A-записью на его IP и открытые порты 80 и 443.

```bash
git clone <репозиторий> && cd <каталог>
cp .env.example .env
DOMAIN=korsik.example.ru docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
docker compose exec app python -m seed.seed   # только для демо: синтетические данные
```

- Caddy (`deploy/Caddyfile`) сам получает сертификат и отдаёт собранную Mini App и `/api`. Наружу открыты только 80 и 443.
- Вход в панель только через «МАКС» (`DEV_ALLOW_NO_INIT_DATA=false`), `MINIAPP_URL` выставляется из `DOMAIN`.
- Демо-функции в проде выключены. Для показа на сервере добавьте в `.env` строку `DEMO_ENABLED=true`: перематывать можно только тестовых и синтетических новичков.
- Адрес `https://<DOMAIN>` один раз прописывается у бота на business.max.ru, подробно в [miniapp/README.md](miniapp/README.md).

</details>

## Как показать

1. `make links` и открыть ссылку тестового новичка в «МАКС» на телефоне: пройти знакомство, задать вопрос («во сколько обед?»), попробовать `/hr` и `/food`.
2. В панели «Ещё», раздел «Демо»: перемотать тестового новичка на 1, 3, 14, 60 день или конец испытательного. Шаги и опросы этого дня придут в чат сразу.
3. Ответить на обращение из панели: ответ придёт новичку. Посмотреть «Аналитику» и сформировать сводку.

## Границы пилота и что дальше

- **Цифры качества оптимистичные:** пороги поиска подобраны на том же эталоне, на котором мерили. На пилоте их надо перепроверить на вопросах настоящих новичков.
- **Чаты команды** заработают, когда HR добавит бота админом в группы «МАКС»: без этого бот не может добавлять туда новичков.
- **Демо-стенд** ходит в облачный GigaChat, потому что у команды нет сервера с видеокартой. На заводе модель ставится на сервер компании одной настройкой (раздел про закрытый контур выше).
- **Что дальше:** пилот на одном заводе, затем остальные площадки Группы. Из отзывов экспертов в очереди баллы и ачивки за шаги адаптации и Корсик как персонаж в стиле компании.
